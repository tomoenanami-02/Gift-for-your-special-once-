# Little Letter ✦ — Amazing Edition

A polished, mobile-first interactive surprise / letter maker.

## What's improved
- Completely redesigned visual UI with glassy cards, aurora lighting, grain, floating particles and richer typography.
- Real animated screen transitions instead of abrupt screen swaps.
- Relationship choices have clear selected states and no "stuck" option behavior.
- Progress bar and step labels update with the active step.
- Receiver letter is **pre-filled automatically** with a personalized starter based on the selected relationship.
- The starter is fully editable: keep it, edit it, or press **Clear everything** and write from scratch.
- Occasion can be custom.
- Mood/vibe selection is reflected in the final letter.
- Interactive question flow animates each answer and advances cleanly.
- Animated reveal and letter presentation.
- Share links + QR code remain supported.
- No account and no backend required; letter data is encoded in the URL hash.

## Run
Open `index.html` in a browser, or deploy the three web files to GitHub Pages.

## Important
Share links contain the letter content in the URL. They are convenient, but not encrypted. Don't put passwords or highly sensitive information in a letter.
